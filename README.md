# The Digital Detective 🔍

**Diwali Independent Learning Assignment — Explore Your Computer · Build a Mini System Report**

## About this project

This repository documents my journey through the Digital Detective assignment, where I investigated how computers work from the ground up: hardware and software fundamentals, the Terminal and command line, operating systems, program execution, number systems and data representation, version control with Git, and computer networking.

Each mission is completed and committed separately, with its own folder and README following the required format.

## Topics explored

- **IPOS cycle** — Input, Processing, Output, Storage and the hardware involved at each stage
- **Hardware and software** — Identifying and classifying components and programs
- **Terminal / CLI** — Navigation, file operations, flags, pipes and package managers
- **Operating system** — Processes, storage, paths, permissions and OS responsibilities
- **Compilers and interpreters** — How programs are translated and executed
- **Number systems** — Decimal, binary and hexadecimal conversions by hand and with Python
- **Text encoding** — ASCII, UTF-8 and why encoding standards matter
- **Git and GitHub** — Version control workflow, branching and Pull Requests
- **Computer networks** — LAN, WAN, DNS, protocols, packet switching and what happens when you open a website

## Running the number converter

The converter program is located at `mission-05-numbers-data/number_converter.py`.

```bash
cd mission-05-numbers-data
python3 number_converter.py
```

Enter any positive decimal number when prompted. The program displays its binary and hexadecimal equivalents.
