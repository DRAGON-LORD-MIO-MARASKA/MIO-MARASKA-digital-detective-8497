## 4. My understanding

### Task 1.1 — Trace one activity using IPOS

**Activity chosen:** Typing and saving a document.

| Stage | What happens | Hardware / component |
|-------|-------------|---------------------|
| Input | I press keys on the keyboard to type text | Keyboard |
| Processing | The CPU processes each keystroke and the word-processing application formats the text | CPU and RAM |
| Output | The typed text appears on the screen in the document window | Monitor / display |
| Storage | When I press Save, the file is written to the internal SSD | SSD (solid-state drive) |

**How the activity flows:** Each keypress sends an electrical signal from the keyboard (input) to the CPU. The processor, with help from RAM, runs the word-processing application that interprets the keypress and updates the document. The result is displayed on the screen (output). When the user saves the file, the data moves from RAM to the SSD for long-term storage.

No major difficulties. Distinguishing between utility software and application software required a moment of thought, but the definitions in the assignment made it clear.

## 6. How I resolved them
Re-read the definitions: application software performs tasks for the user (documents, browsing), while utility software maintains or protects the system (disk management, antivirus).
